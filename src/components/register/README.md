# components/register

报名系统 UI 组件。

## 规划组件

| 组件                   | 说明                                                                                       |
| ---------------------- | ------------------------------------------------------------------------------------------ |
| `RegistrationForm`     | 已登录的个人报名表单。读取本届草稿后开放编辑，草稿和当前承诺使用同一表单值，截止时资料只读 |
| `PositionCapBar`       | 各位置实时名额进度条（接收 Realtime 推送）                                                 |
| `ScreenshotLinkFields` | NJUBox 截图分享链接字段（Rivals 默认 1 个链接，链接内含 5 场截图）                         |
| `RegistrationSuccess`  | 提交回执。聚焦提交状态并链接本届报名进度                                                   |
| `PositionSelect`       | 位置下拉选择（满员自动置灰）                                                               |
