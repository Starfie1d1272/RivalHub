# 赛事规则

当前统一规则为 [NJU Major 赛事规则 v1.1](published/nju-major-v1.1.md)，由公开页面 `/rules` 明确绑定。v1.1 正式发布前的 PR 审阅阶段保留“发布日期待发布”标记；赛委会审定后补入正式发布日期再合并。

[NJU Major 2026 赛事规则 v1.0](published/nju-major-2026-v1.md) 作为已发布历史版本永久保留。

`published/` 中已进入主线的规则原文永久保留，普通代码修复、重构和文档整理不得修改、删除或重命名既有文件。CI 对照基线提交逐文件检查，新增版本进入正常 PR review。赛事规则由赛委会决定，发现代码与规则冲突时先核实决策及实现，不通过改写已发布规则消除差异。

每届 NJU Major 的正赛规模、Play-In 方案、阶段 BO 制、地图池、赛程、名单调整截止时间等具体参数通过赛事公告单独发布。后续规则补充说明新增到相应 supplements 目录，写明适用版本、发布日期及赛委会决定。
