# 文档归档

归档材料保存其形成时的事实与语言，不作为当前实现或赛事政策的 authority。当前技术实现从 [`../README.md`](../README.md) 进入；赛事政策见 [`../rules/`](../rules/)。

| 目录 | 内容 |
| --- | --- |
| [`readiness/`](./readiness/) | 历史 readiness snapshot 与当时能力判断 |
| [`rehearsals/`](./rehearsals/) | 某日期、版本或 fixture 的验收证据 |
| [`compatibility/`](./compatibility/) | 历史迁移与兼容说明 |
| [`process-history/`](./process-history/) | 已完成/被替代的设计、规划和实现过程材料 |
| [`integrations/`](./integrations/) | 已退出当前 runtime 的交接材料与示例 |

重要过程记录包括：

- [`process-history/2.0-convergence.md`](./process-history/2.0-convergence.md)：2.0 上线前模型收敛；
- [`process-history/2.x-product-domains-convergence.md`](./process-history/2.x-product-domains-convergence.md)：早期 2.x 产品领域 planning convergence。

引用归档材料时应注明其历史日期/基线；不要从 archive 反推当前 schema、workflow 或 policy。
