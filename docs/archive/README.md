# 文档归档

归档材料保存其形成时的事实与语言，不作为当前实现或赛事政策的 authority。当前技术实现见 [`../README.md`](../README.md)，赛事政策见 [`../rules/`](../rules/)。

| 目录 | 内容 |
|---|---|
| [`readiness/`](./readiness/) | 历史 readiness snapshot 与当时的能力判断 |
| [`rehearsals/`](./rehearsals/) | 某日期、版本或 fixture 的验收证据 |
| [`compatibility/`](./compatibility/) | 历史迁移与兼容说明 |
| [`process-history/`](./process-history/) | 设计、计划与实现过程材料 |
| [`integrations/`](./integrations/) | 已退出当前 runtime 的交接材料与示例 |

其他既有目录保留相应历史交付物。引用归档材料时应标明其日期和适用上下文。
