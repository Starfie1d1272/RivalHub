## 共享基础设施

### UIA-009 · 单届载入短暂显示空白

**P2 · 性能与状态反馈 · A · R5。** 浏览者和参赛者在切换 `/[seasonSlug]/*` 时上一轮观察到短暂空白。赛事壳保留了最小高度，fallback 只有 `aria-busy` 与名称，详情尚无可见内容。见 `src/app/[seasonSlug]/layout.tsx:32,89`。

保留固定槽位，补轻量可见状态并复用可读的加载语义，单独测慢响应和小屏首屏。双主题从语义底色取值，布局保持可预期。命令 `$impeccable harden`。

### UIA-010 · 正文实际回退到系统字体

**P2 · 实现一致性 · A · R6。** 线上首页、数据中心、忘记密码的正文或标题计算样式为系统栈。SH-01 确认根 `--font-sans` 为空而 body 有 `--font-geist`。Tailwind 将根 alias 在 body 的变量可见之前求值，编译证据见 SH-04。源位 `src/app/layout.tsx:17,58`、`src/app/globals.css:102,156`。

在能解析 Geist 的层定义 alias，保留 Noto Sans SC 与 JetBrains Mono 的既有角色。验证计算样式、字体加载和标题换行，再同步 DESIGN.md。两种主题共用字体系，320px 下复核长标题和字段高度。命令 `$impeccable typeset`。

### UIA-012 · 页面存在嵌套主要地标

**P2 · 可访问性 · A／S · R1。** `/settings/competitive` 和后台样本均见 2 个 `main`，其中 1 个嵌套。根 layout 已提供主要地标，设置与后台 layout 又各提供一个。BP 和 DAK/Mizar 接入页也存在子 `main`，为源码证据。见 SH-03 与 `src/app/layout.tsx:69`、`src/app/settings/layout.tsx:10`、`src/app/admin/layout.tsx:25`、`src/app/[seasonSlug]/matches/[matchId]/veto/page.tsx:24`。[HTML main 契约](https://html.spec.whatwg.org/multipage/grouping-content.html#the-main-element)

在共享壳指定唯一主要地标，局部改用 section/容器，结合标题和跳过导航复核键盘路径。语义在桌面、窄屏和主题间复用。命令 `$impeccable harden`。

### UIA-016 · 全站与通知没有统一的颜色模式状态

**P2 · 主题准备 · A／S · R3。** 根固定 `class="dark"` 和 `color-scheme: dark`，SH-01 在系统偏好非暗色的会话也如此。应用未挂 ThemeProvider，`ui/sonner.tsx:10` 的通知主题单独回退到 system。本轮没有制造业务通知来判断实际通知色。见 `src/app/layout.tsx:54,75`、`src/app/globals.css:151`。

先定义模式与色彩 token 的唯一 owner，再让 HTML、表单原生控件和通知消费同一 resolved mode。切换入口要同时验证窄屏、首帧、无脚本回退和恢复系统偏好。命令 `$impeccable shape`。

### UIA-017 · 赛事颜色覆盖与 Portal 跨了不同 CSS 作用域

**P2 · 主题 · S · R3。** 历史 Rivals 实测赛事容器主色 `#f97316`、根 `#ff6b1a`。现有 `--color-primary`、`--color-ring` 等别名在根求值，直接读 `--color-accent` 的消费者可读取容器覆盖。Dialog、Select、DropdownMenu 的默认 Portal 在外层，HelpTooltip 直接挂 body。自定义色 Portal 的实际呈现仍待专项复现。源位 `src/app/[seasonSlug]/layout.tsx:50–58`、`src/app/globals.css:18–36`、`src/components/ui/{dialog,select,dropdown-menu}.tsx`，编译见 SH-04。

定下品牌主色、赛事主色及其前景的继承边界，在对应层解析兼容别名，并让赛事浮层共享必要变量。用自定义深浅色和 body portal 验证焦点、按钮、选中态。浅色依赖这一步，窄屏抽查浮层溢出与焦点。命令 `$impeccable extract`（规划）或 `$impeccable harden`。

### UIA-019 · 非对阵树页面加载 legacy 样式

**P3 · 性能与隔离 · A · R5。** `/stats` DOM 已挂载 `/brackets-viewer.min.css`，根布局全局引入。文件本地 6,859 B，线上独立 HTTP 响应传输 1,654 B。消费位置为 `BracketView.tsx:401`。证据 SH-07 与 `src/app/layout.tsx:56`。

将 vendor 样式归到对阵树入口，查切换进入时样式是否及时加载。独立控制其暗色和浅色适配，保持原来的局部横滚。命令 `$impeccable optimize`。

### UIA-032 · 自定义赛事色的输入范围超过可读配色范围

**P2 · 主题与可访问性 · S · R3。** `src/lib/seasons/edit.ts:81` 允许六位 hex，`src/lib/utils/color.ts:18–25` 按固定亮度阈值选前景并直接用输入作为焦点色。可复算边界 `#777777` 选现有深前景约 4.37:1，`#111111` 作当前页面焦点色对 `#0a0c10` 约 1.04:1。该计算不代表线上赛事使用这些颜色。

保留赛事主色输入的辨识用途，另由语义规则确定可读文字、填充和焦点对。测试真实赛事与边界样本的两种模式。焦点和小标签在手机上同样受益。命令 `$impeccable colorize`。

### UIA-038 · 读取与失败态的页面几何不一致

**P2 · 实现一致性与响应式 · S · R1。** 赛事信息读取用 narrow、正常用 wide。Stats 正常和读取为 workbench、error 与 not-found 为 wide。社区奖读取只用局部 padding，成功用 wide。源位 `src/app/[seasonSlug]/info/page.tsx:11,29`、`src/app/stats/{page,error,not-found}.tsx`、`src/app/[seasonSlug]/community-awards/page.tsx:13,37`。没有以此推断实测 CLS。

同一路由使用一致的 PageLayout 组合，再保留各自的骨架、错误和正文。320px 复核内外留白，桌面复核内容起点，双主题保持几何。命令 `$impeccable harden`。
