## 技术判断

现有界面具有明确的赛事控制台结构。赛程、参赛确认和赛务进度分别面向真实任务，PageLayout、状态组件和语义 token 在多区已有复用。实现完整性这一项为 **2/4**，关键字段命名、高影响确认、状态壳和局部赛事主题继承仍未达到本轮验收标准。

| 维度 | 分数 | 可核对依据 |
| --- | ---: | --- |
| 可访问性 | 2/4 | 具名 Dialog、排序表头和焦点样式可作为对照。竞技档案 9/12 控件缺关联标签，关键文字和控件边界对比度不足，帮助 Escape 和确认焦点有实测问题。 |
| 性能 | 3/4 | Stats 分视图加载、实时分数按可见性连接、WebGL 按需。HTTP 样本与源码确认全局 legacy CSS 和 BP 静止时钟，赛后资料成本仍待测。本项是有限样本评分。 |
| 响应式 | 2/4 | 320px 多数实测样本保持文档宽度，宽表内部滚动。推演页文档宽 336px，赛事、设置和后台有当前项屏外，带操作的 banner 挤压说明。 |
| 主题 | 2/4 | 深色有语义 token 和局部赛事色。控件边界、危险与选中前景、根别名和 portal 作用域仍有偏离，通知与根模式缺少共同状态。 |
| 实现一致性 | 2/4 | 共享层与赛事专用结构成立。取消、清除、恢复、字段标签、页头和路由 fallback 有具体的跨层差异。89 个 detector 命中中多处为有意的紧凑标签或状态强调。 |
| **合计** | **11/20** | 五维各 0–4 分，与 Critique 的十项 24/40 使用不同量表。 |

### 影响优先级

1. **赛事高影响动作和任务交接。** 一步取消比赛的控件在线出现，调用及清理解说认领由源码确认。名单告警跳转丢范围、比赛进入进行态后仍显示排期编辑，以及清除失败可能留空，集中修正当前任务、允许动作和结果反馈。UIA-001、002、028。
2. **参赛和账号恢复。** 合并锁定说明并给本届帮助。开放 Rivals 草稿覆盖输入和撤销备用邮箱的会话影响是源码确定的路径，在隔离环境验收触发条件。UIA-003、033、035。
3. **先补共享可访问性。** 稳定字段 ID、选择状态、输入边界和必读前景，随后统一 Tooltip、原地确认焦点、Tabs 和筛选反馈。此批能覆盖参赛、办赛和公开数据三类用户。UIA-004、006、013–015、020、022、024。
4. **窄屏与主题逐步迁移。** 320px 推演溢出可独立处理。页面壳、横向导航当前项与字体修正提供同一视觉基线，随后推进赛事配色和 Portal，最后加入浅色入口。UIA-010、012、016–018、021、023、032、038。

### 保留并复用的证据

- 首页的主赛事和下一场、Swiss 轮次及完赛逐图结构表达了产品用途。320px 完赛表和选手历史维持局部横滚，Stats Records 当前导航能自动定位，可作为其他轨道的实现对照。
- 赛事选择器支持键盘检索、Esc 和返回焦点。社区奖按需读证据，等待与结果有可访问状态。Telemetry 分布和趋势图的源码有标题、live 提示及同一读模型的数据表。
- 「我的参赛」区分队伍报名和本人确认。开赛筹备有六阶段，执行、赛程、赛后资料有 URL 视图与稳定返回。完赛回放待办实测能定位到对应展开区。
- 代码已把地图结果更正、解说撤销、删除和回退的影响放进独立确认。迁移取消比赛和撤销邮箱时可复用这些呈现经验。

## 审查口径

主审核对共享层、CSS 作用域、性能和 detector，三个独立区域评估各自走查公开、账号/参赛和后台。源码基线为 `3ac65bdf`，线上页脚为 `2.25.42`。UI 目录在本地标签 `v2.25.42` 到该源码基线之间无差异。本轮区分浏览器观察、源码确定行为和需采样的风险。44 个页面入口有线上 Chrome 样本，13 个仅读源码或 fixture，24 个仅盘点。页面和状态范围见[覆盖矩阵](2026-11-09-coverage.md)。

线上使用现有登录态只读抽查，实际写入、普通管理员、有效票据、开放报名和活跃 BP 保留相应验证边界。浏览器 320、390、768px 抽样不能替代真机、真实读屏、弱网、200% 文本缩放与浏览器渲染性能记录。detector 供问题定位，合规结论需要按 WCAG 条款和真实交互验证。[WCAG 2.2](https://www.w3.org/TR/WCAG22/)

首轮建议按 [PR 方案](2026-11-09-design-system.md#分批-pr-方案)并行处理共享字段和确认契约、赛务防错、参赛草稿/会话，以及独立的 320px 溢出。修复后复查相同范围，再用 `$impeccable polish` 对双主题和视觉层级收尾。
