## 保留的设计实践

- 首页从当前赛事和下一场进入正式赛程。单场完赛用系列分数、地图和半场分数逐层展开，保留赛事专有结构。
- 「我的参赛」先给本人待办，再给队伍、赛事和资料，区分队伍报名结果和个人确认。
- 开赛筹备以六阶段呈现完成、冻结和确认。比赛工作台保留对阵、轮次、排期和返回来源入口。
- 赛况使用文字配合状态色，常用赛程筛选可通过 URL 恢复。紧凑等宽标签和正式赛事信息共同维持「赛事控制台」方向。
