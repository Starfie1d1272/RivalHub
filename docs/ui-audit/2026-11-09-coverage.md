# RivalHub · 全站审查覆盖矩阵

2026-11-09 冻结。源码为 `3ac65bdf`，线上页脚为 `2.25.42`。`v2.25.42` 到审查基准的 `src/` 无差异。范围为 **81 个页面入口**（29 个全站与个人、17 个赛事、17 个平台后台、18 个单届后台）及 6 个 layout。重定向入口与动态模板各按一个入口计。

**B** 为实际 Chrome 路由样本，**S** 为具体源码或已读 fixture，**I** 为仅盘点；**C** 单独标记断外网的合成组件或 SSR 夹具，不计为完整路由浏览。首轮 44 B、13 S、24 I；冻结时 **53 个有 B，28 个仅 S，0 个仅 I**。B 只适用于表中列明的样本与状态，不能从一条路径推导同模板下所有角色已验收。首轮桌面 1414px，抽样 320/390/768px；末轮匿名 Chrome 为 1280/320px，隔离主题样本为 1280/390/320px。

末轮线上只开无会话的白名单页面，拦截自动发出的 POST、数据请求和外部连接；未再打开已登录生产页。服务器 Preview 未运行，本机没有可用 Local Supabase；未启动两者。隔离夹具用合成账号、名单和请求，不依赖任何远端数据库或邮件。方法见 [FZ-01](evidence/2026-11-09-technical.md#fz-01--匿名浏览与环境)。

## 交叉复核

- 参赛评估发现竞技与设置地标问题，主审在相同路由独立测得两个 main 和无当前项语义，后台评估在管理壳复现相同结构。
- 公共、参赛和后台分别测得统计、空输入边界和审计文字对比。主审用实际颜色重新计算，将必读文字、控件边界和填色前景分别归入 UIA-004、015、018。
- 主审在 Stats 独立操作 Enter/Escape，复核指标帮助；公共和参赛在不同宽度复核自制 Tabs。赛事、设置和后台的活动项屏外归到同一导航根因。
- 后台在线只定位取消比赛控件，主审复核 click handler、事务和状态机。草稿、撤销邮箱、BP tick 与赛后数据量以源码确定的路径和需实测的后果分别记录。
- 末轮交叉核对：两路评估比对了队长确认、选秀终态与取消事务；主审用实际 CSS 和组件检查局部色、Portal、边界色，按现有根因合并。只读角色走查和模拟分开记证。
