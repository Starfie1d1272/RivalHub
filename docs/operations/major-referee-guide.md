# NJU Major 裁判与管理员操作手册

本手册是赛事当日操作说明；长期政策以 [NJU Major 赛事规则](../rules/nju-major.md) 为准。完美平台的按钮、命令与房间能力会变化，赛前由赛委会确认本次实际可用流程。

## 赛前准备

1. 从赛事赛前工作区核对本届 frozen profile（Major-24 或 Major-32）、正式参赛队、最终种子、冻结名单与赛程。资格和人数以本届已发布规则与冻结配置为准。
2. 打开比赛总览，查看自己的当前/下一场及尚未认领的比赛。有转播时沿用解说认领；无人认领不阻止正常人工比赛。
3. 核对有效首发及系统展示的资格阻塞。队伍未提交时，系统按正常时间窗口生成合法默认首发；Veto start 同事务重新核验并定格阵容，不要求管理员额外逐场确认。
4. 双方在 Veto Room 完成 BP。按单场工作台的六项复制与其余核对指引手工创建 Perfect 房间；网站不宣称已创建第三方房间。
5. 房间内的准备、暂停和现场开始按平台实际流程执行。临时换人、缺席或身份争议使用管理员例外/裁决入口，保留原因与审计。

## 逐图赛务与制作

无 Mizar 时在工作台人工记录本图正式结果。自动源核验正常时以观察为主，无需重复人工录分。身份、阵容、连续性或赛果冲突优先处理；人工接管只限当前地图，迟到点击须刷新，下一图健康开始后可恢复自动记录。Mizar 设备换机、OBS 与节目控制仍在 Mizar。

正式地图完成后可并行补齐平台计分板与准备下一图。图间从正式完成时间正计时，10 分钟提示仅用于准备/催促，不处罚、不自动判负。系列赛 2:0 结束后不准备 Map 3。

每张实际完成地图均需完整基础计分板及 Demo 分析结果，无转播也一样。去 Perfect 下载 Demo，用本地 RivalHub Demo Uploader 解析并同步 evidence；原始 .dem 不上传网站。DAK 已确认后，OCR 只补平台 Rating/RWS/WE，不覆盖 gameplay、身份或验证记录。需要处理的 Demo 仍在本场恢复入口核对。

官方完赛、比赛数据齐备、制作资料齐备分别显示；有解说认领才需要制作资料，无人认领为不适用。B 站状态无法获取时显示「无法确认」，不阻塞比赛。真实 Perfect/Mizar/OBS 现场联调与生产上线须单独验收。

## BP、暂停与回档

- 按规则书执行 BO1 / BO3 / BO5 BP；若平台流程受限，保留已完成选择并记录裁判决定。
- 每图每队最多 3 次战术暂停；加时每阶段额外 1 次。技术暂停应记录原因，单图原则上累计不超过 15 分钟。
- 回档/中断依据平台记录和最后可靠状态处理。已经形成实质进程的回合不自动回档；将争议写入赛事记录后升级赛委会。

## 迟到、弃权与重新排期

默认宽限为计划时间后 15 分钟，系统不会自动判负。裁判须选择并记录原因：延长宽限、重新排期、A 弃权、B 弃权或双方无法参赛的裁决。前场延误、平台故障、赛委会调度、已报备课程/考试、双方同意短延后均可作为合理理由。

弃权、判负、结果录入与更正一律通过既有 Match/Result/Recovery 操作完成，填写 reason、二次确认并保留 audit。不要另建线下结果表或绕开 canonical matches。

## 赛后与争议

1. 录入或确认比分；如有异议先暂停最终确认并收集平台记录、录像和双方陈述。
2. 结果更正前查看下游影响；已开始或结束的后续比赛不自动回写，由赛委会裁决恢复方案。
3. 代打、借号、小号、伪造资料、作弊等提交纪律流程。个人处罚、队伍资格、比赛裁决与荣誉可分别处理。
4. 全部比赛后确认最终名次，再授予冠军、亚军、MVP 等荣誉。荣誉撤销不自动递补。
5. 归档前核对结果、处罚、申诉和重要 audit，保留最小必要内部材料。
